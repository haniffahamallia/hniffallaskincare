NIFFALLA SKINCARE — WEBSITE LANDING PAGE
========================================

Isi folder:
- index.html : struktur halaman
- style.css  : desain responsif, warna biru soft / putih / abu
- script.js  : pencarian, pengurutan, keranjang dan pesan WhatsApp
- assets/    : enam gambar yang diberikan pengguna

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Untuk publikasi, unggah seluruh isi folder ke GitHub Pages atau hosting statis.

Fitur:
- Landing page dengan foto produk pertama sebagai hero.
- Tentang brand, koleksi produk, manfaat, promo, FAQ.
- Pencarian produk dan urut nama.
- Keranjang belanja dengan jumlah, hapus produk, dan total sementara.
- Tombol WhatsApp mengarah ke +6285159977358 dengan template pesan yang diminta.
- Responsif untuk ponsel, tablet, dan desktop.

Catatan:
- Harga produk di halaman adalah contoh sementara dan dapat diubah di index.html.
- Klaim manfaat dan komposisi perlu disesuaikan dengan label resmi produk.
- Font nama brand ditampilkan memakai teks dekoratif yang dikirim pengguna; hasil persis font gambar tidak bisa dijamin di semua perangkat.
